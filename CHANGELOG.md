# Changelog

## 0.1.0

First release.

- Remote MCP server with five Douyin (抖音) tools: video search, video details, creator profiles with their posts, comments, and Douyin Shop product search.
- Apify sign-in (OAuth) for Claude, ChatGPT, Cursor, VS Code, Codex and other remote MCP clients; token header as an alternative.
- Claude Code plugin with the Douyin skill: run flow for longer requests, input recipes, tool chaining and field sets.
- Client configuration examples, code examples for Python, JavaScript and HTTP, and an MCP Registry manifest.
- README in English and Simplified Chinese.
